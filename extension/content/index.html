moz_places

Row detail

Calls the real calculate_frecency synchronously on the main thread, through Places' main connection, so the browser can stutter while a page is being timed. It only reads. Pages are picked at random, plus the busiest tenth as many again, since those are where the cost shows. Each page gets one untimed warm-up call, and the chart plots the median of the timed calls against how many moz_historyvisits rows the page has.
